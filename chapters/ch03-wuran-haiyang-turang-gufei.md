# 第二编 污染防治 · 海洋、土壤、固体废物（第 334–545 条）

## Core Idea
本部分覆盖污染防治编的海洋、土壤、固体废物三个分编。土壤防治以"预防＋风险管控＋修复"为特色（责任人不明的由使用权人担责）；固废治理坚持减量化、资源化、无害化，危险废物实行最严格管控。

## 制度与原则

### 第四分编 海洋污染防治（第 334–393 条）
- 陆源污染控制（347-…）：入海排污口设置与监管；**禁止向海域排放油类、酸液、剧毒废液、放射性废水等（危险物质清单）**；海水养殖污染防治。
- 工程建设项目（362-370）：海岸工程与海洋工程环评、防污设施三同时；海洋油气勘探开发防污。
- **废弃物倾倒（371-379）**：**倾倒许可证制度**；禁止倾倒的废弃物类别；倾倒区选划。
- **船舶污染防治（380-393）**：船舶防污设备与证书；船舶含油污水、生活污水、垃圾处理；载运危险货物船舶要求；船舶排放控制区。

### 第五分编 土壤污染防治（第 394–463 条）
- **土壤污染防治原则与体制（398-401）**：国务院统一监管；**每十年至少一次全国土壤污染状况普查（401）**。
- **预防为主（412-429）**：有毒有害物质防控；土壤污染重点监管单位制度（414）；农用地禁用行为——禁止向农用地排放重金属超标污水、污泥、清淤底泥、尾矿、矿渣（422）；禁止生产销售国家明令禁止的农业投入品（424）。
- **风险管控和修复（430-463，核心）**
  - 责任链条：调查 → 风险评估 → 风险管控/修复 → 效果评估 → 后期管理（430）。
  - **责任人规则（439）**：土壤污染责任人负有修复义务；**责任人无法认定的，土地使用权人实施**；费用由责任人承担（440）；责任人变更由承继者承担（441）。
  - **农用地分类管理（444-452）**：优先保护类（划为永久基本农田，445）、安全利用类、严格管控类三类。
  - **建设用地风险管控和修复名录（453-463）**：省级生态环境部门会同自然资源部门制定；名录内地块管控措施；修复后效果评估合格方可移出（461）；用途变更、收储、转让前须调查（462）。

### 第六分编 固体废物污染防治（第 464–545 条）
- **三化原则（466）**：减量化、资源化、无害化；全过程管控。
- **零进口（477-478）**：禁止境外固废进境倾倒、堆放、处置，实行固废零进口。
- **跨省转移（476）**：出省贮存、处置须申请许可。
- 工业固废（487-498）：台账制度（489）；委托运输利用处置须核实受托方资质并签合同（490）；尾矿分级分类管理（497）。
- **生活垃圾（499-515）**：分类制度（499）；**产生者责任（506）**——分类投放义务；厨余垃圾资源化（514）；**产生者付费制度（515）**。
- 建筑垃圾（516-520）：分类处理制度、联单管理（518）；工程施工单位编制建筑垃圾处理方案报备（520）。
- 农业固废（521-527）：秸秆、农膜回收；**退役风电叶片、光伏组件、废旧动力电池精细拆解（523）**；污泥处理（525-526）。
- **危险废物（528-545，最严格）**：名录管理（529）；识别标志（531）；管理计划与台账（532）；**经营许可（534）**——从事收集、贮存、利用、处置经营须取得许可证，禁止无证经营；分类贮存（535）；**转移联单（536）**——电子/纸质联单，跨省转移须批准；禁止与旅客同车（537）；**禁止过境转移（543）**；医疗废物按危险废物管理（544）；**环境污染责任强制保险（484）**——收集贮存运输利用处置危险废物单位须投保。

## 关键概念
- **土壤污染责任人**：负有风险管控修复义务的主体，无法认定时由土地使用权人承担（439）。
- **农用地分类管理**：优先保护/安全利用/严格管控三类（444）。
- **建设用地风险管控和修复名录**：省级名录管理，未达标不得移出（453、461）。
- **危险废物经营许可**：无证经营构成犯罪的移交司法（534）。
- **固废零进口**：禁止境外固废进境（477-478）。

## 适用思维
- 土壤问题三步走：查责任人（污染者→使用权人）→ 定地块类型（农用地三类/建设用地名录）→ 走流程（调查-评估-管控修复-评估-后期管理）。
- 固废合规：先判定废物类别（一般固废/危险废物/生活垃圾），危险废物全链条特许。
- 海洋合规：陆源看排污口、工程看环评三同时、倾倒看许可、船舶看设备证书。

## 常见误区（Anti-patterns）
- **误以为土壤修复义务只属于污染者**：责任人无法认定或变更时，使用权人/承继者须担责（439、441）。
- **忽视危险废物转移联单**：未运行联单跨省转移属违法（536）。
- **把危险废物当一般固废处理**：无证经营危险废物重罚并可入刑（534、1178）。
- **遗漏退役光伏风电设备处置责任**：生产者负有建立回收体系义务（523、979）。

## 要点
1. 土壤修复"谁污染谁负责，找不到人由使用权人兜底"。
2. 危险废物全生命周期（产生-贮存-转移-处置）均须按特许规则运行。
3. 海洋、固废、土壤均受"排污许可＋三同时"通用框架约束。
